# RuneCode — ผจญภัยด้วย Python

พลังติดตัวช่วยให้ทั้งสามอาชีพวางแผนต่างกัน: นักผจญภัยตีต่อเนื่องได้โบนัส 20%/40%, อัศวินตั้งรับการโจมตีจริงแล้วคืนสูงสุด 2 MP และพ่อมดใช้ `focus()` ก่อนสกิลในเทิร์นเดียวกันเพื่อเพิ่มพลังดาเมจ 25% เปิด “พลังอาชีพ” ในแผงผู้เล่นเพื่ออ่านเงื่อนไข และใช้ “ตรวจแผน” ดูผลก่อนรัน [รายละเอียดพลังติดตัว](docs/HERO-TRAITS.md)

เกมเรียน Python ภาษาไทย 6 บท 24 ห้อง สร้างใหม่จากแนวคิดในแผน พร้อม 3 อาชีพ การต่อสู้ตามเทิร์น คำใบ้ 3 ระดับ สมุดบทเรียน ร้านค้า และบันทึกบนเครื่อง

โจทย์ปรับให้ง่ายและสั้นสำหรับ ม.4 ที่เริ่ม Python: ห้องฝึก 18 ข้อและบอสทบทวน 6 ข้อ โจทย์อังกฤษคำง่าย ๆ 1–2 ประโยค ฝึกทีละเรื่อง บทฟังก์ชันและคลาสมีโครงให้เติม พร้อมคำใบ้สั้น ตัวอย่างและตัวตรวจที่ตรงกัน [รายการโจทย์](docs/SOURCE-CURRICULUM.md)

บอสทบทวนเรื่องหลักของแต่ละบทโดยไม่รวมหลายหัวข้อยากในโปรแกรมเดียว ดู [รายละเอียดบอส](docs/BOSS-CHALLENGES.md) เก็บความคืบหน้าและร่างเดิมไว้ ร่างเก่าอาจต้องปรับให้ตรงโจทย์ปัจจุบัน

ขณะเล่นท่าต่อสู้ editor จะไฮไลต์บรรทัดคำสั่งที่รันจริง โดยไม่เลื่อนหน้าหรือแย่งโฟกัส แก้โค้ดแล้วไฮไลต์รอบนั้นจะหยุด ส่วนคำสั่งเสริม **ตั้งสมาธิ `focus()`** ใช้ 1 AP ฟื้นสูงสุด 3 MP ได้ครั้งเดียวต่อเทิร์น หาก MP เต็มให้ใช้สกิลก่อนแล้วค่อยฟื้น หาก MP ไม่พอสามารถเขียน `focus()` ก่อนสกิลได้ แต่ต้องมี MP รวมพอและใช้ไม่เกิน 3 AP ทั้งแผน ปุ่มแทรกอยู่ในแผงสกิลฝั่งผู้เล่นและหน้ารายละเอียดเดิม

ตัวแปรข้อมูลการต่อสู้ใน Python เช่น `hp` และ `mp` อ่านค่าตอนต้นเทิร์น ไม่อัปเดตระหว่างรันโค้ด คำสั่งที่เก็บไว้จะถูกตรวจและทำงานตามลำดับเมื่อโค้ดผ่านทั้งหมด จึงไม่มีการเสียทรัพยากรครึ่งเทิร์นเมื่อแผนไม่ผ่าน

ตรวจสอบโปรเจกต์ด้วย `npm run typecheck`, `npm test` และ `npm run build` ไฟล์เกมที่สร้างแล้วอยู่ใน `dist/` ส่วน dependencies และ Python runtime เตรียมใหม่ได้ด้วย `npm ci`

ยาที่ซื้อระหว่างมีห้องค้างอยู่จะเก็บไว้สำหรับห้องใหม่ ไม่หายเมื่อเล่นต่อหรือชนะ ส่วนการเปิดหลายแท็บจะตรวจเซฟที่บันทึกสำเร็จจริงก่อนเขียน หากอีกแท็บบันทึกไปแล้ว ให้โหลดบันทึกล่าสุดก่อนเล่นต่อ นำเข้า หรือเริ่มใหม่

## เปิดเล่นในเครื่อง

ต้องมี Node.js 22.12+ หรือ 24+

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (`http://127.0.0.1:5173/` โดยปริยาย) `postinstall` จะคัดลอก Pyodide 314.0.7 จากแพ็กเกจที่ตรึงเวอร์ชันไป `public/python/` จึงไม่ต้องพึ่ง CDN ระหว่างเล่น ฟอนต์และภาพเป็นไฟล์ภายในทั้งหมด

ในหน้าต่อสู้ โซนขวารวม editor ปุ่มรัน สกิล MP และยาไว้ด้วยกัน ส่วนโซนซ้ายมีฉาก ท่าถัดไปของศัตรู และบันทึกการต่อสู้ เลือก **โจมตีปกติ** หรือ **สกิลอาชีพ** อย่างใดอย่างหนึ่งต่อเทิร์น เกมจะเปลี่ยนคำสั่งในโค้ดตามที่เลือกทันที โดยเก็บข้อความ คอมเมนต์และโครงบทเรียนไว้ ป้องกันและยาเลือกใช้เสริมได้ภายใน 3 AP จากนั้นกด **รันโค้ด** เพื่อส่งเทิร์น เปิดรายละเอียดจากไอคอนหนังสือหรือ **สกิล** ในแถบ editor ใช้ Ctrl/Cmd+Z เพื่อ Undo การเปลี่ยนท่าได้ ลูปยังต้องปรับจำนวนครั้งเอง เพราะสกิลใช้ 2 AP และใช้ได้ครั้งเดียวต่อเทิร์น ดู [กติกาการเลือกท่า](docs/OFFENSIVE-CHOICE.md)

กด **ตรวจแผน** เพื่อรัน Python และดูผลคาดการณ์ HP, MP ยา และ AP โดยยังไม่เสียเทิร์น เมื่อพอใจจึงกด **รันแผนนี้** หรือกลับไปแก้โค้ดได้ ถ้า Python ผิด เกมจะไฮไลต์บรรทัดและมีปุ่ม **ไปบรรทัด** เพื่อพาไปแก้โดยตรง

แต่ละอาชีพมี **3 สกิล** ให้เลือกพร้อมชื่อ เอฟเฟกต์ และค่า MP จริง ท่าเดิมใช้ `skill()` ส่วนท่าใหม่ใช้ `pierce()`, `stun()` หรือ `burst()` ตามอาชีพ เลือกแล้วโค้ดเปลี่ยนให้และ Undo ได้ สกิลขัดจังหวะหยุดการตอบโต้เทิร์นนี้ แต่พิษเดิมยังทำงาน เมื่อ AP เกิน รายละเอียดใต้ผล Python จะบอกบรรทัด จำนวนครั้ง AP และจุดเริ่มลูป พร้อมเสนอจำนวนครั้งที่พอในเทิร์น โดยไม่เปลี่ยนจำนวนรอบเอง ดู [รายละเอียดสกิลและ AP](docs/SKILLS-AND-AP.md)

คำแนะนำแสดงใต้ปุ่มรันทันที ก่อนแผงสกิล ใช้ข้อความขนาด 16px และเลื่อนให้เห็นข้อผิดพลาดโดยไม่เปิดคีย์บอร์ดเอง ผลพิมพ์ยาวเลื่อนอ่านในกรอบได้ด้วยเมาส์หรือคีย์บอร์ด จำกัด 128 ครั้งและ 8,192 ตัวอักษรต่อการรัน รวมบรรทัดว่าง

คำแนะนำภาษาไทยบอกสิ่งที่ควรลองต่อสำหรับทั้ง 18 แนวคิด เช่น เรียกฟังก์ชันที่ประกาศไว้ ตรวจเงื่อนไขก่อน `return` หรือเช็กชนิดค่าก่อนอ่านสมาชิก ข้อผิดพลาดดัชนี เมธอด กุญแจข้อมูล และการแปลงค่ามีคำอธิบายไทยพร้อมรายละเอียดเดิมของ Python ปุ่มไปบรรทัดใช้ตำแหน่งจากโค้ดจริง หากแนวคิดนั้นยังไม่มีในโค้ดจะให้คำแนะนำโดยไม่เดาบรรทัด

คำใบ้มีสามระดับ: ชี้แนวคิด → ชวนสังเกต → ตัวอย่างฝึกเรื่องใกล้ตัว ระดับสามให้ลองคาดผลลัพธ์ก่อนกดเปิดดู แล้วนำแนวคิดไปใช้กับแผนต่อสู้ของคุณ โค้ดตัวอย่างและข้อความอ่านได้ที่ 16px ย้อนระดับหรือปิดได้ตลอด โดยเก็บร่างโค้ด เทิร์น ทรัพยากร และดาวตามเดิม

แถบศัตรูบอกช่วงของบอสและแนวทางรับมือท่าถัดไป ส่วนสถานะพิษแสดงกับข้อมูลผู้เล่น พร้อมจำนวนเทิร์นที่เหลือ หน้าแรกโหลดส่วนควบคุมก่อนฉาก และโหลด editor เมื่อเข้าห้อง ถ้าไฟล์เครื่องมือโหลดขาด ปุ่ม **บันทึกแล้วโหลดใหม่** จะเก็บห้องปัจจุบันก่อนกู้หน้าเกม

เกมใหม่ปิดเสียงไว้ เปิดได้จากไอคอนเสียงด้านบนหรือตั้งค่า เสียงโจมตีและสกิลประจำอาชีพดังตามจังหวะโดนเป้า ส่วนโล่ ยา และผลต่อสู้มีเสียงสั้นของตัวเอง ปิดเสียงหรือออกจากห้องแล้วหยุดทันที โค้ดผิดและ **ตรวจแผน** ไม่ส่งเสียง การลดการเคลื่อนไหวกับการเปิดเสียงเลือกแยกกันได้

ฝึกห้องที่ผ่านแล้วเพื่อเพิ่มดาวได้ โดยเก็บสถิติที่ดีที่สุดและไม่รับเหรียญรางวัลซ้ำ หน้าผลแยกคะแนนรอบนี้กับสถิติเดิม เมื่อจบครบ 24 ห้องจะมีบทสรุปการเดินทาง ห้องแนะนำให้กลับไปฝึก สมุดบทเรียน และปุ่มส่งออกความคืบหน้า

เมื่อชนะหรือแพ้ ผลการต่อสู้แสดงในฝั่งเขียนโค้ดและพาไปเห็นปุ่ม **ไปห้องถัดไป** หรือ **ลองห้องนี้อีกครั้ง** หลังแอนิเมชันจบ กด Tab จากหัวข้อเพื่อเลือกปุ่มต่อได้ทันที หากเปิดหน้าตั้งค่าอยู่ เกมจะไม่แย่งตำแหน่งหรือโฟกัสของหน้าต่างนั้น แพ้แล้วยังเก็บโค้ดเดิมและเหรียญไว้

โค้ดผิดไม่เปลี่ยนการต่อสู้และไม่หักดาว ใช้คำใบ้หรือตรวจแผนได้เสมอ ดาวคิดจาก HP ตอนชนะ: มากกว่า 60% ได้ 3 ดาว มากกว่า 30% ถึง 60% ได้ 2 ดาว และชนะด้วย HP ที่เหลือไม่เกิน 30% ได้ 1 ดาว เปิดดูช่วง HP ของฮีโร่ในภารกิจและหน้าผลได้ เซฟเก่าและดาวดีที่สุดยังเก็บไว้ตามเดิม

สมุดบทเรียนค้นหาได้ทั้งคำไทยและชื่อแนวคิด Python กรองเฉพาะบทเรียนที่ผ่าน และเปิดบทปัจจุบันให้อัตโนมัติ ร่างโค้ดล่าสุดของแต่ละห้องแยกจากตัวอย่างอย่างชัดเจน กดคัดลอกได้โดยไม่เปลี่ยนโค้ดหรือเทิร์นที่กำลังเล่น หากคลิปบอร์ดใช้ไม่ได้จะมีวิธีคัดลอกเอง บันทึกส่วนตัวเก็บและส่งออกพร้อมเซฟตามเดิม

## ตรวจและ build

```sh
npm run test
npm run test:e2e
npm run build
npx vite preview --host 127.0.0.1 --port 4173
```

Unit/integration tests รัน Python จริงผ่าน Pyodide ทดสอบคำตอบ 72 แบบและกติกาครบ 24 ห้องทุกอาชีพ Browser tests ใช้ Playwright; Chrome ชี้ executable ที่ติดตั้งใน Windows อยู่แล้ว Firefox/WebKit ติดตั้งด้วย `npx playwright install firefox webkit` ตั้ง `TEST_URL` เพื่อทดสอบ production preview

การทดสอบแคมเปญผ่าน UI ตั้งแต่เลือกอาชีพจนจบทั้ง 24 ห้องแยกไว้ใน `npx playwright test --config=playwright.journey.config.ts` เพราะใช้เวลานาน ตั้ง `ALL_BROWSERS=1` เพื่อรวม Firefox/WebKit กับ Chrome/Edge แต่ละกรณีเริ่มด้วยบริบทเบราว์เซอร์ใหม่ ใช้คำตอบอ้างอิงและ Python จริง ไม่ซื้ออัปเกรด ไม่เติมความคืบหน้า และไม่แตะเซฟในหน้าที่คุณเปิดเล่นอยู่ ผลทดสอบอัตโนมัติไม่ใช่ผลทดลองกับผู้เรียนหรือมือถือจริง

`dist/` เป็น static build พร้อม service worker เก็บเกมและ Python runtime เมื่อ cache สำเร็จจึงเล่นออฟไลน์ได้ อย่าเปิดด้วย `file://`; ใช้ HTTP localhost หรือ HTTPS โฮสต์ static ที่รองรับ `.wasm` เป็น `application/wasm` ขนาด runtime ประมาณ 13.6 MB ก่อนบีบอัด ไม่รวมโค้ดเกมและฟอนต์ เป็นการดาวน์โหลดครั้งแรก

การอัปเดตออฟไลน์ตรวจ SHA-256 ของแต่ละไฟล์ ใช้ Python และไฟล์เดิมที่ไม่เปลี่ยนต่อได้ หากไฟล์เสียจะดาวน์โหลดใหม่ รุ่นใหม่ที่เก็บไฟล์ครบจะรอให้ปิดแท็บเกมเดิมทั้งหมดก่อนเริ่มใช้งาน เพื่อให้แท็บเดิมยังโหลดฉากและ editor รุ่นเดิมได้ หน้าตั้งค่าบอกเมื่อมีรุ่นใหม่พร้อมอัปเดต ให้รอจนขึ้น “บันทึกแล้ว” แล้วปิดแท็บเกมทั้งหมดและเปิดใหม่ อัปเดตที่ไม่ครบไม่แทนที่รุ่นเดิมที่ยังเล่นได้ การบันทึกความคืบหน้าอยู่ใน IndexedDB แยกจาก cache ของเกม

ครั้งแรกเกมให้ Python โหลดพร้อมก่อนเริ่มเก็บไฟล์สำหรับออฟไลน์ เพื่อลดการแย่งเครือข่ายระหว่างการเริ่มเล่นกับงานเบื้องหลัง ตัวติดตั้งลองใช้ไฟล์จาก HTTP cache ก่อนและตรวจ SHA-256 เสมอ หากเนื้อหาเก่าหรือเสียจะดาวน์โหลดใหม่ ไม่ประกาศว่าเล่นออฟไลน์ได้จนรุ่นนั้นติดตั้งครบและเริ่มทำงานแล้ว เวลาโหลดบนโฮสต์และอุปกรณ์จริงยังต้องวัดแยกจากชุดทดสอบ

เมื่อแก้โค้ดหรือเปลี่ยนข้อมูลเกม ป้ายจะเปลี่ยนเป็น **กำลังบันทึก** ทันที และแสดง **บันทึกแล้ว** เมื่อเก็บสถานะปัจจุบันสำเร็จ หากอีกแท็บมีเซฟใหม่กว่า แท็บเก่าจะแสดง **หยุดบันทึก** และขอให้โหลดข้อมูลล่าสุด เพื่อป้องกันการเขียนทับ ยังส่งออกข้อมูลในแท็บนั้นเป็นไฟล์ได้

## ขอบเขตของระบบ

- React + TypeScript + Vite, Phaser 3.90 สำหรับฉากพิกเซลต้นฉบับ, CodeMirror 6 สำหรับ editor
- `src/engine.ts` เป็น pure combat simulation; renderer ไม่ใช่เจ้าของสถานะเกม
- `src/content.ts` ประกาศบทเรียน ห้อง และคำตอบอ้างอิง; `src/runtime/` รัน Python ใน Worker แยก namespace
- ตรวจโครงสร้าง AST คู่กับส่วนที่ทำงานจริง โดยแยกต้นฉบับจากโค้ดที่ใช้เก็บหลักฐาน ไม่รับฟังก์ชันที่ยังไม่เรียกหรือการอ่านข้อมูลในแขนงที่ไม่เข้า รองรับโค้ดบรรทัดเดียวและการเรียกผ่านชื่ออื่น พร้อมรักษาลำดับประเมินค่าและบรรทัดข้อผิดพลาด ตรวจ action/AP/MP ก่อนเปลี่ยนเกม
- บทสตริงและชุดข้อมูลดูชนิดค่าที่อ่านจริง จึงรับข้อความจากการคำนวณหรือ `.upper()` และ list/tuple/set จากฟังก์ชันสร้างหรือ comprehension ได้ด้วย หากเปลี่ยนตัวแปรไปเป็นคนละชนิดก่อนใช้ ตัวตรวจจะไม่นับเป็นหลักฐานของชนิดเดิม
- จำกัดเวลารัน 3 วินาที ไม่รวมโหลด runtime; ปุ่มหยุด terminate worker และโหลดใหม่ได้
- โหลด Python ครั้งแรกให้เวลาสูงสุด 4 นาทีแยกจากเวลารันโค้ด เพื่อรองรับเน็ตช้า หากโหลดค้างมีปุ่มลองใหม่โดยไม่เสีย draft หรือเทิร์น การติดตั้งออฟไลน์ครั้งแรกยังอาจโหลด runtime พร้อมกัน จึงควรตรวจเวลาและขนาดรับส่งบนโฮสต์จริงก่อนเผยแพร่
- `src/storage.ts` ตรวจ schema และเก็บ IndexedDB; export/import อยู่ในตั้งค่า
- เป็นเกมเล่นคนเดียวบนเครื่อง ไม่ใช่บริการประมวลผล Python สำหรับบุคคลอื่น และไม่อ้างว่า AST restrictions เป็น security sandbox สำหรับโค้ดที่ไม่เชื่อถือ

ภาพทั้งหมดเขียนใหม่ด้วย pixel matrices และ Phaser Graphics ใน `src/art/pixels.ts` และภาพไอคอนสกิล SVG ใน `src/ui/SkillIcon.tsx` ไม่มีการใช้ภาพหรือโค้ดจากเกมอ้างอิง ฟอนต์ Chakra Petch ใช้ตาม SIL Open Font License ที่มากับแพ็กเกจ `@fontsource/chakra-petch`

เมื่อ install/build จะสร้าง `THIRD-PARTY-NOTICES.txt` ให้ static build โดยเก็บข้อความต้นฉบับจากแพ็กเกจที่ล็อกเวอร์ชันไว้ รวม OFL ของฟอนต์ และข้อความของ Pyodide/Python/Emscripten จากเวอร์ชันที่ใช้จริง แหล่งต้นฉบับและ SHA-256 อยู่ใน `vendor/runtime-notices/` ขั้นตอนสร้างใช้ไฟล์ในเครื่องและตรวจเวอร์ชันกับ hash โดยไม่ดาวน์โหลดระหว่าง build ข้อความเหล่านี้แนบไปกับเกมและ cache ออฟไลน์ด้วย

## การทดสอบกับผู้เล่นจริง

ยังต้องให้ผู้เริ่มเรียนจริงอย่างน้อย 5 คนลองบทแรก และตรวจคีย์บอร์ดสัมผัสบน iPhone/Android จริง ก่อนอ้างว่าเกณฑ์การใช้งานกลุ่มเป้าหมายผ่านครบ Browser emulation และ WebKit automation ไม่ทดแทนการทดสอบกับผู้ใช้หรืออุปกรณ์จริง

ใช้ [คู่มือทดลองบทแรก](docs/BEGINNER-PLAYTEST.md) สำหรับงานและเกณฑ์บันทึกผล โดยตารางผลยังว่างและยังไม่มีการอ้างว่าผ่านการทดสอบกับคนจริง
