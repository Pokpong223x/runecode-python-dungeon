# Beginner playtest

Participants: five beginners age 12+ who have not used this game. Use a mixture of desktop keyboards and real Android/iPhone devices. Do not collect names or upload their code; record anonymous participant numbers and observations locally.

Give each person these tasks without demonstrating the solution:

1. Choose a hero and find the first lesson.
2. Read the task and explain what they think `print()` and `attack()` will do.
3. Write or adapt code, run it, and observe the result.
4. Make a syntax error, read the feedback, and correct it using hints if needed.
5. Explain the enemy's next intention and try `defend()`.
6. Complete the first room, reload, and find their progress and draft.
7. On a phone, open the keyboard, indent a line using the toolbar and locate Run and Stop.

Record: task completion without an answer, time to first run, misunderstood labels, unnecessary taps, keyboard obstruction, hint level used, and the player's explanation in their own words. Keep observation separate from inference. Stop when a participant is uncomfortable or asks to finish.

Acceptance: at least four of five complete the first run and explain the basic command effects without being told the answer. Fix recurring points of confusion and repeat the affected tasks before claiming that criterion has passed.
