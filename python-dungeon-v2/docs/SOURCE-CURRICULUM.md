# โจทย์สำหรับ ม.4 ที่เริ่มเรียน Python

ปรับตามคำขอวันที่ 27 ตุลาคม 2026 ให้โจทย์สั้นและไม่ซับซ้อน: 18 ห้องเรียนรู้และ 6 บอสทบทวน โจทย์เป็นอังกฤษคำง่าย ๆ ประมาณ 1–2 ประโยค เมนูเป็นไทย

แต่ละห้องฝึกเรื่องหลักเรื่องเดียว ไม่บังคับรวมหลายวิธีไว้ในคำตอบเดียว บทฟังก์ชันและคลาสมีโครงให้เติมเพียง 1–2 จุด คำใบ้และสรุปใช้ประโยคสั้น ตัวอย่างฝึกไม่มีคำสั่งต่อสู้และใช้ข้อมูลต่างจากโจทย์

## กติกาและการตรวจ

โจทย์ฝึกใช้การโจมตีหนึ่งครั้ง เลือก attack(power) หรือ skill(power) ได้ ค่าพลังเป็นจำนวนเต็ม 1–3 และทั้งแผนใช้ไม่เกิน 3 AP การป้องกัน ยา และสมาธิยังเป็นตัวเลือก บอสใช้กติกาต่อสู้เดิม

ตัวตรวจใช้ Python จริง ตรวจแนวคิดและเงื่อนไขที่เขียนในโจทย์ ไม่บังคับวิธีที่ตัดออกแล้ว เช่น การกำหนดตัวแปรซ้ำ การบวกข้อความ การหาค่าสูงสุด–ต่ำสุด หรือคำนวณหลายคุณสมบัติของ object คำตอบเทียบเท่าและตัวแปรกลางยังใช้ได้ โค้ดที่ไม่ได้รันหรือคำนวณแล้วไม่ใช้จะไม่ผ่านเงื่อนไขที่ต้องใช้ค่านั้น

`src/sourceCurriculum.ts` เป็นเจ้าของโจทย์ฝึก ชื่อภายใน `SOURCE_` และ `LessonContract.sourceExercise` เก็บไว้เพื่อความเข้ากันได้ รหัสห้อง ลำดับปลดล็อก และ SaveGameV1 คงเดิม ความคืบหน้าและร่างเดิมไม่ถูกรีเซ็ต แต่ร่างอาจต้องแก้ให้ตรงโจทย์ปัจจุบัน

ทุกห้องมีคำตอบอ้างอิงสามแบบ รวมตีปกติเมื่อ MP หมด คำตอบผิดและการตรวจแผนไม่เสียเทิร์นหรือทรัพยากร
